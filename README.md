# grok-router

`grok-router` is a command-line program. The binary takes an optional global `--config` path and one subcommand.

Subcommands: `list`, `search`, `add`, `set-default`, `remove`, and `skill`. They are registered and not implemented yet.

```bash
cargo run -p grok-router -- --help
cargo run -p grok-router -- --version
```
